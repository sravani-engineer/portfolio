🚀 Featured Project

Hand Gesture Recognition — Failure Analysis Under Real-World Conditions

Built a real-time hand gesture recognition system using Python, MediaPipe, OpenCV, and scikit-learn.

Evaluated using session-based validation across 12 sessions, 5 users, and ~22K frames to simulate real-world deployment instead of relying on random train-test splits.

Identified a ~12% performance drop under challenging conditions and discovered that gesture similarity (open vs four) was the primary source of model error.

Key Insight: Model errors were driven more by gesture similarity than environmental variation.

Tech: Python, OpenCV, MediaPipe, scikit-learn
