🚀 Featured Project

Hand Gesture Recognition — Real-World Failure Analysis

Built a real-time ML system and analyzed performance under distribution shift.

  • 📊 Evaluated on 12 sessions, 5 users, ~22K frames
  • 🔬 Used session-based validation to prevent data leakage
  • 📉 Identified ~12% performance drop in real-world conditions
  • ⚠️ Discovered major failure: open vs four confusion

Key Insight: Model errors were driven more by gesture similarity than environmental variation.

View Code Live App

💡 Why This Matters

Most ML systems report high accuracy using random splits, which hides real-world failure. This project demonstrates how performance drops under distribution shift and why evaluation strategy is critical for reliable deployment.

🧠 What I Learned

  • High accuracy does not guarantee real-world performance
  • Session-based validation prevents data leakage
  • Feature representation limits model performance
  • Failure analysis is critical for production ML
